# 🧪 SQA & Manual Testing Portfolio

Welcome to my Quality Assurance portfolio repository! This project showcases complete end-to-end manual testing workflows, defect management, and web element locator design.

## 📋 Included Artifacts

* **Test Case Suite:** Comprehensive functional, boundary value, and negative test cases.
* **Defect Reports:** Structured Jira bug tickets with step-by-step reproduction instructions and severity ratings.

* **Web Locators:** Custom relative XPaths and CSS Selectors designed for dynamic web elements.

* **Documentation:** Markdown, PDF
